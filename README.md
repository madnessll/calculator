# Инструкция

## Запуск калькулятора

1. Находимся в корне проекта, пишем команду: ./build/project/calculator -a 10 -b 3 -o + 13
2. 10 - первое число, 3 - второе число, '+' - операция

## Возможные операции

1. '+' - сложение
2. '-' - вычитание
3. '*' - умножение
4. '/' - деление
5. '^' - возведение в степень
6. '*' - факториал числа. В данном случае второе число игнорируется

## Примеры команд

1. calculator -a 5 -b 3 -o +    
2. calculator -a 10 -b 2 -o /   
3. calculator -a 5 -b 0 -o !
